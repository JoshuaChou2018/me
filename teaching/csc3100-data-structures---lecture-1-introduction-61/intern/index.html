Math 4

Geometric Series

🧮 Geometric Series

S = 1 + r + r² + … = 1/(1-r)   (0<r<1)
r = 2
📐 Derivation

Let S = 1 + r + r² + … (1)

Then rS = r + r² + r³ + … (2)

(1) - (2): S - rS = 1

S = 1/(1-r)

Logic

Proof Techniques

Click to enlarge

❌ Proof by Counterexample

To disprove: find one concrete example that violates the statement.

Claim: Fk ≤ k²

F11 = 144 > 11² = 121 ✗

🔁 Proof by Induction

1

Base Case: Prove for n=1

2

Hypothesis: Assume true for n=k

3

Inductive Step: Prove for n=k+1

Click to start the proof…

🔄 Proof by Contradiction

Assume √2 = p/q (reduced)
2 = p²/q² → p² = 2q²
p² even → p even
p=2k → 4k² = 2q² → q² = 2k²
q is also even!
Contradiction!
